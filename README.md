# Government & Community Analytics

**Tools:** R · Tableau · ArcGIS · SQL · Excel  
**Organization:** Strategic Spartanburg, Spartanburg, SC  
**Timeline:** Summer 2024 – Summer 2025

## Overview
Developed during two consecutive summers as a Community Data Analyst 
for Strategic Spartanburg. Built analytical tools used by government 
officials and community partners to understand food insecurity and 
economic mobility across Spartanburg County, SC.

## What I Built

**Food Insecurity Dashboard**
- Mapped food insecurity variables against UN classification standards 
  across census tracts
- Built interactive filtering by geography and indicator type
- Applied weighted composite scoring to identify highest-need areas
- Used ArcGIS for spatial analysis across county boundaries

**Economic Upward Mobility Dashboard**
- Applied the Urban Institute's five-domain framework: Rewarding Work, 
  High-Quality Education, Opportunity-Rich Neighborhoods, Healthy 
  Environment, and Responsive Governance
- Built categorical visualizations across poverty indicators
- Presented findings to local government officials and community 
  stakeholders to inform funding and policy decisions

## Data Sources
- US Census Bureau (American Community Survey)
- Municipal datasets — Spartanburg County
- UN food security classification standards
- Urban Institute Upward Mobility Framework

## Skills Demonstrated
R · Tableau · ArcGIS · SQL · Excel · Geospatial Analysis ·

## Impact
Findings were presented directly to local government officials and 
used to guide resource allocation decisions across Spartanburg County.
